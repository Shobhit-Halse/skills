# Skills For Engineers

A collection of production-grade AI agent skills for mobile and software engineers.

These skills encode production patterns, defensive engineering best practices, and edge-case prevention so AI agents write battle-tested code instead of naive snippets.

## Install

```bash
npx skills@latest add <your-username>/skills
```

## Reference

- **[api-expo](./skills/api-expo/SKILL.md)** - Production-grade API integration for React Native and Expo. Covers `expo/fetch`, `expo-secure-store`, TanStack Query v5, rate limiting (429s), exponential backoff with full jitter, idempotency keys, offline support with NetInfo, and error handling.
